# `tsconfig.app.json`における`include`の意義

```
"include": ["src"]
```

と記載されている場合、TypeScriptはまず`src/`配下の対象ファイルを確認し、それらのファイルにある`import`や`export ... from`を<br>
辿って追跡し、参照先も型チェックの対象に加える。この時、参照先が`src/`の外にあっても読み込まれる。<br>
<br>
例えば

```
"include": ["src", "somewhere"]
```

のように追加すると、`somewhere`下の任意の階層に何らかのtsファイルを作った場合、<br>
まだどこからも`import`も再エクスポートもしていない場合においても<br>
ファイルを作成した時点でフロントエンドによる型チェック対象になる。<br>
追加しなければそのようなことは起こらず、<br>
フロントエンド側が参照している場合に限って型チェック対象となる。
